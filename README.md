# 静态部署版使用说明

本目录是无需自建后端服务器的完整 H5。将目录内 4 个网页文件原样上传到静态托管平台，即可获得微信公众号菜单可直接访问的 HTTPS 链接。

## 文件

- `index.html`：页面与表单字段
- `styles.css`：蓝白科技风和手机端适配
- `app.js`：表单校验、提交和成功提示
- `config.js`：需求接收邮箱

## 数据接收

表单通过 FormSubmit 转发至 `cn778899@163.com`。第一次在正式网页提交后，该邮箱会收到 FormSubmit 的激活确认邮件；必须点击确认，之后的客户需求才会正常到达。该方案无需公司维护后端服务器。

## 推荐部署：GitHub Pages

1. 新建一个公开 GitHub 仓库，例如 `research-request-h5`。
2. 将本目录中的 4 个网页文件上传到仓库根目录。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待发布完成，页面会显示形如 `https://用户名.github.io/research-request-h5/` 的 HTTPS 地址。

中国大陆微信访问稳定性要求较高时，推荐将同一组文件上传到腾讯云 COS 静态网站托管，并绑定已备案的公司域名。GitHub Pages 在部分网络环境下可能访问较慢。

## 公众号菜单

登录微信公众平台，在“自定义菜单”中添加“实验需求提交”，内容选择“跳转网页”，粘贴部署后的 HTTPS 地址并发布。正式发布前请在微信内完成一次表单提交，并到 163 邮箱点击 FormSubmit 激活邮件。

## 注意

FormSubmit 是第三方表单转发服务，免服务器但仍依赖第三方可用性。如果未来对数据合规、国内网络稳定性或客户线索管理要求提高，建议迁移到腾讯文档/飞书表格接口或公司 CRM。
